Veranschaulichendes Projekt für den Unterricht. Schrittweise Umsetzung wird durch Übungsaufgaben begleitet und parallel werden fachbezogene theoretische Inhalte vermittelt. 

>Ausgangssituation:
>Lesen Sie nun den folgenden Ist-Ablauf. Dieser beschreibt, wie Menschen heute, ohne das TaskBoard, neue Aufgaben notieren und verwalten:
>
>„Wenn jemand eine neue Aufgabe festhalten möchte, nimmt er ein Stück Papier oder öffnet eine Notiz-App. Er schreibt einen Titel und gegebenenfalls eine kurze Beschreibung hinein. 
>Wenn die Aufgabe wichtig ist, markiert er sie farbig oder setzt ein Ausrufezeichen daneben. Danach wird die Notiz in eine Liste gelegt bzw. in der App gespeichert. 
>Später wird die Liste manuell durchgesehen und erledigte Aufgaben werden durchgestrichen oder gelöscht.“


Quellen sind vom Leistungsträger der Maßnahme gestellte Fachbücher, Aufgabenstellungen in einem Word-Dokument und Web-basierte Publikationen in der weiten Welt des Internets.
